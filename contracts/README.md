# Contracts

JSON schemas and fixtures shared by the pipeline, Bob, the renderers and the frontend.

- **Owner:** Daniel (D-01).
- **Contract v1 was frozen at H3.** Later changes need a PR reviewed by Daniel and a heads-up to the team.

## Contents

- `schema-v1.json`: JSON Schema of the extended `DossierResult` contract, generated from `backend/app/models.py`
  with `python -m backend.app.generate_contracts` (from the repo root). `backend/tests/test_contracts.py` checks it.
  Do not edit it by hand.
- The models the live product uses (what Bob must return and the validated dossier) are in
  `backend/app/contracts/schema_v1.py`: `AuditorOutput` and `Dossier`. The audit prompt embeds the `AuditorOutput`
  schema directly. `python -m app.contracts.export` (from `backend/`) writes them as JSON Schema; note that it
  targets the same `schema-v1.json` path, so do not run it until the team decides which schema that file holds.

## Fixtures

- `fixtures/bob-session-facturaya.json`: the real result of the Bob session the showcase replays
  (26-09, `evidence-auditor` with 4 subagents, 1.15 bobcoins; `imported` mode). The session ran with a Spanish
  prompt; for the English submission the prose of its 12 findings (title, explanation, recommendation) was
  translated. Ids, categories, severities, evidence (paths, lines, snippets) and the session stats are exactly as
  Bob recorded them. The original recording is in `fixtures/recorded-es/`.
- `fixtures/bob-events-facturaya.jsonl`: activity of that same session (Bob's stream-json plus the events of its
  log: plan, tools, subagents, turns), without the content of the files it read. Kept exactly as recorded; the
  showcase replays it at its original pace.
- `fixtures/bob-evidence-auditor-facturaya.json`: the 25-09 session (6/6 expected findings). Kept as recorded (its
  prose is in Spanish) for the evaluation and the tests; one snippet was updated to the English sample's text.
  Re-importable with `--import`.
- `fixtures/dossier-example.json`: example dossier (`execution_mode: example`), used only when
  `ALLOW_NON_LIVE_MODES=true`.
- `fixtures/valid-dossier.json`, `fixtures/partial-dossier.json`: valid and partial examples of the extended
  contract, generated by `generate_contracts.py`.
- `fixtures/migration_options_expected.json`: expected structure of `migration_options` (not a live Bob run).
