# Checklist de envío

- [ ] Repositorio público con licencia MIT, creado a partir de la [plantilla oficial IBM Hackathon](https://github.com/watsonxhackathon/ibm-hackathon-template) (`.gitignore` y `.bobignore` de seguridad presentes y sin modificar sus patrones).
- [ ] `SECURITY.md` presente; sin credenciales ni API keys expuestas en ningún archivo (revisar también capturas de `bob-sessions/`).
- [ ] README final: problema, uso de Bob, arquitectura, quick start, enlaces.
- [ ] URL pública de la demo respondiendo.
- [ ] Video de **máximo 3 minutos** (MP4), con al menos 90 segundos de demo en vivo (`docs/demo-script.md`).
- [ ] `bob-sessions/<jean|felipe|daniel|edgar>/`: al menos una captura del resumen de sesión de Bob de **cada** integrante (tareas J-11, F-15, D-10, E-09), sin credenciales visibles.
- [ ] `docs/pre-event.md` actualizado y veraz.
- [ ] `docs/bob-usage.md` completo y reporte exportado en `bob-report/`.
- [ ] Tabla de precisión/recall en `evaluation/`.
- [ ] Tag `v1.0` creado; recorrido de aceptación pasado 3 veces.
- [ ] Slides de negocio con cifras de mercado con fuente.
- [ ] Formulario de lablab.ai enviado, incluyendo:
  - [ ] **Long Description** (máximo 500 palabras): problema, solución, usuarios objetivo, diferenciación.
  - [ ] **IBM Bob Usage Statement** (máximo 500 palabras): cómo, dónde y bajo qué arquitectura se usó IBM Bob 2.0 (basar en `docs/bob-usage.md` y `bob-report/`).
- [ ] Envío verificado desde otra cuenta.
